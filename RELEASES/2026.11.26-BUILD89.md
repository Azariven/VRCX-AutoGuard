## Included behavior

- Public profile Bio and Bio Links checks against enabled exact-domain rules such as `hexed.cc` and `oversee.lol`.
- Sender-attributed friend requests and supported group invite/join-request/recommendation notifications are treated as profile-review signals. The notification itself does not cause a block; the sender's profile must match an enabled rule. Whitelisted users are skipped.
- Friend review and manual whitelist workflows are included in the project.

## Testing caveats

The current-world scanner is designed to focus on players in the active instance, but complete live VRChat event wiring and behavior still require in-client testing. CI success verifies the tested code paths build and unit tests pass; it does not certify every live social event or guarantee bot detection.

AutoGuard is an experimental defensive utility. A configured domain match is not proof of malicious activity. Review rules and whitelist entries before enabling automatic blocking. Start with manual review.

## Installation

1. Exit any running VRCX process.
2. Run `VRCX_2026.11.14_Setup_x64.exe`.
3. Complete setup, then launch VRCX AutoGuard.
4. Review domain rules, whitelist, and automatic-block settings before use.
